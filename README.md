# EcoPonto+

- **Android:** [baixar o app](https://github.com/ecopontoplus/ecopontomais-app/releases/latest/download/ecopontomais.apk). Depois de baixar, toque no arquivo para instalar.
- **Web (computador e iPhone):** https://ecopontomais.expo.app
